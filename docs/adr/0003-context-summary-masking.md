# 0003 上下文摘要遮蔽与 replace 完整 id 列表

- 状态：已接受（2026-11-16）

本轮在 `context_summary_enabled` 分支接通摘要：先在裁剪后的视图上做遮蔽（非 summary 保留，summary 按其 `replace` 删除已累积消息后前插），再在遮蔽后的列表上按“最近 N 轮、起点回退到最近一条 user”切出摘要区间与完整保留区，把摘要区间送入空实现的普通/增量摘要函数，生成 `content` 为空、`replace` 为**直接遮蔽消息 id 完整列表**（不再是区间端点）的摘要并 append 进 history，本次 build 返回 `[新摘要, 完整保留区]`。取舍是：完整 id 列表比区间端点长，但能精确表达不连续遮蔽并让每条摘要自描述；增量摘要只记旧摘要 id + 本次压缩区 id（直接遮蔽），不并入旧摘要的历史 id，因此 history 中的旧摘要必须保留并被遮蔽算法按序遍历，否则会漏遮蔽；摘要内容本轮留空、后续再补。这个决定难以回退：`replace` 会随会话持久化，消费方按完整列表与直接遮蔽语义实现；若将来改成传递闭包或允许删除旧摘要，需要迁移数据并改遮蔽算法。
