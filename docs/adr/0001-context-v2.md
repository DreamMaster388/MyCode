# 0001 上下文构建体系 v2

- 状态：已接受（2026-11-15）

本轮把 `agents/context` 拆成 history（原始记录+摘要）、pruner（裁剪占位）、summary（摘要占位）、builder（组装）四层，删除旧 GSSC builder 与 `ObservationTruncator`，工具结果不再截断、全文入 history。截断、摘要、历史召回三个上下文治理模块分别由三个开关控制，默认全关；本轮三个分支跳过或空实现。三开关全关时发送历史并丢弃 summary 消息；摘要开关开启时保留 summary 消息，等待后续摘要算法。这样取舍是用全文入 history 换可回溯性、接受长会话溢出风险，并用模块留空换算法设计空间；代价是删除旧流水线后撤销成本较高，恢复截断需重新引入预算、落盘与模型可见性策略。
