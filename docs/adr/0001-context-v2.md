# 0001 上下文构建体系 v2

- 状态：已接受（2026-11-15）

本轮把 `agents/context` 拆成 history（原始记录+摘要）、pruner（裁剪）、summary（摘要）、builder（组装）四层，删除旧 GSSC builder 与 `ObservationTruncator`，工具结果不再截断、全文入 history。builder 保留两条链路：朴素拼接，以及截断+摘要+历史召回；后者由三个开关控制，默认全关，本轮只实现朴素链路，链路 2 保留可运行骨架、打开时告警回退。这样取舍是用全文入 history 换可回溯性、接受长会话溢出风险，并用链路 2 留空换算法设计空间；代价是删除旧流水线后回退成本较高，恢复截断需重新引入预算、落盘与模型可见性策略。
