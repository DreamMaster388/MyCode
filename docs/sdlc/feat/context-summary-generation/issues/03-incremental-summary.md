# 03: 增量摘要生成与降级

**要构建什么：** 摘要触发且已有旧摘要时，把旧摘要原文与新增压缩区一起交给主 LLM，合并成一份新的完整结构化摘要；成功时替换旧摘要内容，失败时保留旧摘要原文并追加新增消息的 role/id。增量路径端到端可用，并补齐 README 的摘要行为与已知限制。

**阻塞于：** 02（复用普通摘要的 LLM 调用、输入渲染与降级实现）

**状态：** done
