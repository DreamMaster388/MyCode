# 01: 工具结果全量进入上下文

**要构建什么：** 用户让智能体执行工具后，工具结果完整进入历史，下一次模型请求能看到全文；不再截断、不再落盘、不再出现“完整内容见路径”的提示。旧上下文构建路径本轮暂不改动。

**阻塞于：** 无（可立即开始）

**状态：** ready-for-agent

- [ ] 智能体执行返回超长文本的工具后，下一次 LLM 请求包含完整工具文本，没有截断标记，也没有指向落盘文件的提示。
- [ ] 工具执行不再创建落盘文件；主链路不再调用旧截断器。
- [ ] 工具结果作为 tool 消息写入历史，保留 tool_call_id，历史顺序和请求顺序不变。
- [ ] 错误/部分成功前缀、步数/预算、收尾等现有行为不变。
- [ ] 集成测试用假 LLM 和假工具覆盖全文可见性；不联网、不启动 Docker。
